# GolfHeadCam UE5 工程

高尔夫简化挥杆与头戴相机仿真，运行逻辑使用原生蓝图。适用 **Unreal Engine 5.8.3**。

## 打开工程

使用页面的 **Code → Download ZIP** 下载并完整解压，或克隆本仓库。用 UE5.8.3 打开根目录 `GolfHeadCam.uproject`，保持同级 `Config` 与完整 `Content`。

加载 `/Game/GolfHeadCam/Maps/L_GolfPractice` 并点击 Play。初始为右肩后方第三人称、动作待命；移动鼠标直接环绕人物。

| 操作 | 功能 |
|---|---|
| Tab | 显示界面鼠标或返回环绕 |
| 控制台播放和暂停 | 开始或暂停挥杆及球运动 |
| Space / R；P | 从头播放；暂停或继续 |
| WASD / Q、E / Shift | 相机平移 / 下降、上升 / 加速 |
| Home / V | 恢复肩后机位 / 切换头戴视角 |
| T | 显示或隐藏实际球轨迹 |
| B / G | 头戴畸变开关 / 标定网格 |

人物与骨架复用 Epic 官方 Third Person 模板。头戴相机固定在 head 骨骼，球杆附着 hand_r。球按初速度、重力和碰撞实时运动，轨迹记录实际位置。相机控制台采用继承的 Widget Blueprint。

当前公开内容仅为工程和启动说明。演示材料正在本地审核，审核后再上传。已保存视频面板需要对应 MP4，目前工程下载不附这两段文件；实时挥杆、相机控制、球运动和镜头效果可正常使用。
