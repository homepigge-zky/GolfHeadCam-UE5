GolfHeadCam｜自由第三人称相机说明
适用引擎：Unreal Engine 5.8.3
操作说明更新：2026-10-17。

一、快速使用

打开 GolfHeadCam.uproject，运行 /Game/GolfHeadCam/Maps/L_GolfPractice。
每次启动均为角色右肩后方的第三人称、动作时间 0 秒待命；默认鼠标环绕，镜头畸变、标定网格和视频面板关闭，不自动播放。
先点击控制台“播放”才开始挥杆；启用和调整相机不会启动动作。
运行后直接移动鼠标即可环绕人物，无需右键或 F；WASDQE 仍可直接移动相机。
Tab 显示鼠标以点击界面，再按 Tab 返回环绕。左下“自由相机”和 F 仍可开关导航，退出时同时停止环绕。
自由模式下右下角提供“机位微调”面板；按 Tab 显示鼠标后，10 个按钮可调整位置和方向。
“复位第三机位”恢复本次启动时的第三相机位置和朝向；不会重置动作或球。
鼠标环绕和键盘移动均不需要按住右键；Tab 是环绕与控制台鼠标之间的切换入口。
再次点击“自由相机”或按 F 退出。退出后第三相机保持刚调整的位置和方向，微调面板隐藏。

二、鼠标微调与按键

自由模式下，右下角“机位微调”提供以下 10 个按钮：
前进／后退：沿当前相机前后方向，每次移动 25 cm。
左移／右移：沿当前相机左右方向，每次移动 25 cm。
升高／降低：沿世界 Z 轴升降，每次移动 25 cm。
向左看／向右看／抬头／低头：每次改变朝向 5°。
这些按钮在界面模式下只需单击；Tab 可返回鼠标环绕，键盘移动也无需右键。
主卡“复位第三机位”用于恢复启动机位，和动画“重新开始”是独立操作。

原快捷键保留：
F：切换自由模式；进入时自动选择第三人称，退出时保留当前机位。
移动鼠标：围绕人物上身参考点环绕，不需要按住鼠标按键。
Tab：显示鼠标以操作界面／返回鼠标环绕。
直接按 W/S：沿当前相机的前／后方向移动。
直接按 A/D：沿当前相机的左／右方向移动。
直接按 Q：沿世界 Z 轴下降。
直接按 E：沿世界 Z 轴上升。
移动键 + Shift：以 3 倍速度移动。
Home：在普通第三人称或自由模式下恢复本次启动肩后机位；不要求按住右键或先按 F。

鼠标环绕默认启用，Tab 切到界面模式后可点击按钮。W/S 依照相机朝向，因此向上或向下看时，
前后移动也可能改变高度；Q/E 则始终使用世界竖直方向。
停止移动鼠标并松开移动键后按 Home，可避免复位后又立即继续移动。
点击头戴／第三人称按钮或按 V 切换会退出自由模式；回到第三人称后按 Tab 可继续环绕观察。
在头戴视角下，移动鼠标、移动键、Tab 和 Home 不会切走头戴相机。
镜头预设和网格按钮会选择头戴视角，因此也会退出自由模式。

三、速度、朝向和运行内机位

默认 FreeCameraMoveSpeed=150 cm/s，即 1.5 m/s；Shift 倍率为 3，默认加速为 450 cm/s。
默认 FreeCameraLookSensitivity=2.0。它乘在 UE 已处理的鼠标输入增量上，可调范围 0.01–10；不是原始像素到角度的标定值，也不是 FOV。
相关设置位于 /Game/GolfHeadCam/Blueprints/BP_GolfGolfer 的类默认值／关卡实例。
bFreeCamera 为自由模式状态；bOrbitMouseActive 表示是否使用鼠标环绕，由 Tab 切换。
ThirdCameraHomeTransform 保存本次启动的第三相机变换，首次鼠标接管不会重摆默认肩后机位。

F 退出再进入、切到头戴再回第三人称，均使用本次运行里保留的 ThirdCamera 机位。
Home 恢复启动机位，而不是另一个固定的世界坐标常量，能适应启动时的关卡实例设置。
这些调整只存在于本次运行，不会写入关卡资产；结束 Play、重新运行或关闭工程后不会自动恢复这次调整。
自由观察相机不使用碰撞阻挡，能穿过简单场景几何；若难以找到人物，点击“复位第三机位”或在第三人称下按 Home 返回。

四、与挥杆、头戴相机和视频的关系

自由相机只修改 ThirdCamera 的位姿；人物整体位置与朝向不随鼠标环绕改变，挥杆动画可独立继续。
按钮微调、复位、F、Tab、WASDQE 移动、鼠标环绕及 Home 均不改变动画时间、播放速率或暂停状态。
播放中的动作继续播放；暂停的动作仍保持暂停，可以从不同角度查看同一姿态。
球使用原生运动组件实时计算飞行和碰撞，轨迹记录实际球心；人物与球杆的骨骼绑定不受自由观察影响。
HeadCamera 仍绑定 head 骨骼，头戴 FOV、内参和镜头预设没有改成自由镜头投影。

打开“已保存视频”会先退出自由模式、隐藏微调面板并屏蔽自由相机输入，然后按原面板流程暂停实时场景。
视频面板打开期间，F、Tab、Home、鼠标和移动键不能控制场景相机，底层机位按钮也不可操作。
关闭后解除屏蔽，保持界面操作及场景暂停；第三人称下按 Tab 恢复环绕，按“播放”继续挥杆。
视频仍是原有无畸变基线成片，浏览和移动相机不会重新编码、覆盖或录制新视频。
电影模式拒绝自由相机输入；原有 Level Sequence、MRQ 输出和正式报告保持各自原版本定义。

五、原生蓝图实现入口

角色：/Game/GolfHeadCam/Blueprints/BP_GolfGolfer。
运行界面：/Game/GolfHeadCam/UI/WBP_GolfCameraConsole。
界面父类：/Game/GolfHeadCam/UI/WBP_CameraControl。
WBP_GolfCameraConsole 是真实子 Widget Blueprint，继承父类原有布局、按钮事件和媒体逻辑，
由 BP_GolfHUD 创建并加入视口；共同布局和事件仍在父蓝图中维护。
主要新增函数为 InitializeFreeCamera、ToggleFreeCamera、StopFreeCamera、SetFreeCameraCapture、
HandleFreeCameraInput、ProcessFreeCameraNavigation、UpdateFreeCameraPose、ResetFreeCameraPose、
SetFreeCameraUIBlocked。集成界面提供自由模式、复位及 10 个鼠标微调按钮，并保留视频模态输入屏蔽。
所有运行逻辑保存在原生蓝图，不需要作者 Python 脚本、bridge、自定义 C++ 或新外部插件。
原 Space/R/V/P/B/G 操作保留；其与自由模式及视频面板的作用范围见前文。

实时球飞行与历史轨迹（2026-10-17）

运行后先按 T 开启轨迹，或按 Tab 显示鼠标后点击“显示实时轨迹（T）”。轨迹默认关闭。
击球前没有预览曲线；球飞到哪里，金色轨迹就延伸到哪里，落地弹跳和滑动也会记录。
轨迹读取 GolfBall 每帧的实际世界位置，不用发射参数预先生成整条曲线。
隐藏轨迹只改变显示，后台继续记录本次击球；再次显示能看到已飞过的部分。重新开始／复位时清空旧轨迹。
轨迹线半径默认 0.8 cm，最多保留 2048 段；超出时移除最早一段。线段本身无碰撞。
球使用原生 ProjectileMovementComponent，根据初速度、世界重力、场景碰撞、反弹和摩擦实时更新。
播放／暂停同时控制挥杆和球；即使四秒挥杆结束后球仍在运动，也能在界面暂停、继续，继续不会重发一球。
打开视频面板会暂停球并隐藏轨迹；关闭后保持暂停。已有 MP4 仍是先前版本，不是本次实时运动的录像。
鼠标环绕、Tab、WASDQE、Home 和人物骨骼附着保持原有作用，不因轨迹开关改变。
实现保存在原生蓝图、运动组件、ISM 和材质中，没有自定义运行时 Python 或 C++。
当前验收见 Output/Validation/RealtimeTrajectory；以前 BallTrajectory 的预测路径检查仅是历史记录。
