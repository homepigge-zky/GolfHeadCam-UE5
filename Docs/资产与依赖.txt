GolfHeadCam｜资产来源、运行依赖与迁移
交付说明更新｜2026-10-17（原基础版：2026-10-16）。包含原生可编辑工程、媒体、文档与验证证据。

一、引擎与必要插件

开发与验证目标为 Unreal Engine 5.8.3，GolfHeadCam.uproject 的 EngineAssociation 为 5.8。
本机引擎位置：<UE_ROOT>。换机器后不需要保持这个引擎安装路径；需安装兼容引擎版本。
没有自定义 C++ 游戏模块，不需要为了运行本项目额外编译工程 C++。

uproject 显式启用的 Epic 引擎内置插件：
  MovieRenderPipeline：Movie Render Queue、输出预设／队列、PNG 和原生 H.264 MP4 导出所需。
  ElectraPlayer：相机控制台内两段已保存 MP4 的原生解码与播放。
  GameplayStateTree：从官方模板保留的内置插件依赖。
  ModelingToolsEditorMode：从模板保留，仅 Editor 平台目标启用。
MovieRenderPipeline 和 ElectraPlayer 的内置依赖由 UE 插件依赖机制启用。
UMG、Media/MediaAssets 是引擎内置界面与媒体框架模块，不是需要另购或下载的外部插件。
本项目未引入外部插件、第三方动作包、外部运行库或另购 Marketplace/Fab 内容。

PythonScriptPlugin 和编辑器作者脚本只在资产制作阶段临时使用，不是游戏运行或界面重渲染的依赖。
正式重渲染使用保存的 Level Sequence、MRQ 配置与队列，可完全通过 UE 编辑器界面完成。
H.264 MP4 编码使用 UE5.8 原生 MovieRenderPipelineMP4Encoder；无需单独安装 FFmpeg 才能使用该预设。

Epic 官方 Third Person Blueprint 模板：
  人物 SKM_Manny_Simple、相关骨架及模板动画／输入／关卡资源。
  原模板目录 Characters、ThirdPerson、Input、LevelPrototyping 等继续保留，便于依赖完整和继续开发。
  模板原地图仍为 /Game/ThirdPerson/Lvl_ThirdPerson。
  这些是 Epic 提供的资源，不能表述成全部原创建模或真人动作捕捉数据。

本工程实现并保存的原生资产：
  BP_GolfGolfer：操作、挥杆播放、头骨／手骨附着、相机选择、球轨迹、电影模式和镜头开关。
  BP_GolfHUD：运行时创建原生子界面 WBP_GolfCameraConsole 并加入视口。
  BP_GolfGameMode、BP_GolfRenderGameMode：交互／导出模式，导出模式不显示控制台。
  UI/WBP_CameraControl：父 Widget Blueprint，保留可编辑 UMG 布局、相机／镜头按钮和独立视频回放逻辑。
  UI/WBP_GolfCameraConsole：真实继承 WBP_CameraControl 的子 Widget Blueprint，作为当前运行界面入口。
  UI/Media/MP_SavedGolf、MT_SavedGolf：原生播放器和媒体纹理。
  UI/Media/MS_GolfHead、MS_GolfThird、M_UI_SavedGolf：相对路径媒体源和原生 UI 显示材质。
  AS_GolfSwing：设定关键姿势后生成并烘焙的 4 秒骨骼动作。
  L_GolfPractice：简化练习场、摆位和灯光。
  球杆、练习垫、球、靶标：UE BasicShapes 简单几何体及项目自建材质。
  M_HeadLensDistortion：Brown–Conrady 8 次逆映射展开的原生材质图，无 Custom HLSL。
  M_CalibrationGrid：原生材质节点绘制的网格。
  MI_HeadLens_Barrel、MI_HeadLens_Pincushion：桶形／枕形原生材质实例，复用原畸变材质图。
  Content/Movies/GolfHead.mp4、GolfThird.mp4：原正式视频的便携副本，不是新增录制。
  LS_Golf_HeadCamera、LS_Golf_ThirdPerson：使用相同动作时间轨的双视角序列。
  LS_Calibration_*：四条固定姿态、固定相机的畸变对照序列。
  MRQ_Golf_1080p60、Q_GolfViews：原生导出预设与队列。

AI／作者工具的角色：辅助阅读要求、查询引擎源码／API、编排并生成原生蓝图／动画／材质／序列资产、
整理验证记录和文档。临时 Python 用于编辑器制作资产，不在游戏运行时执行，也不替代蓝图运行逻辑。

四、明确的简化假设

挥杆为简化关键姿势演示；球按初速度、重力和场景碰撞实时飞行、弹跳及滑动减速。击球时刻与初速度可调，不计算杆头碰撞冲量、空气阻力或自旋升力。
头戴相机采用固定骨骼局部安装；没有额外头戴设备的软组织晃动或独立稳定器模型。
镜头内参和畸变系数为仿真假设；没有宣称实物标定、真实曝光噪声、滚动快门或光学色差的准确再现。
记录中的数学残差、编辑器轨迹检查和最终渲染图像检查是不同验证层次，不能互相替代。

实时球飞行与历史轨迹（2026-10-17）

运行后先按 T 开启轨迹，或按 Tab 显示鼠标后点击“显示实时轨迹（T）”。轨迹默认关闭。
击球前没有预览曲线；球飞到哪里，金色轨迹就延伸到哪里，落地弹跳和滑动也会记录。
轨迹读取 GolfBall 每帧的实际世界位置，不用发射参数预先生成整条曲线。
隐藏轨迹只改变显示，后台继续记录本次击球；再次显示能看到已飞过的部分。重新开始／复位时清空旧轨迹。
轨迹线半径默认 0.8 cm，最多保留 2048 段；超出时移除最早一段。线段本身无碰撞。
球使用原生 ProjectileMovementComponent，根据初速度、世界重力、场景碰撞、反弹和摩擦实时更新。
播放／暂停同时控制挥杆和球；即使四秒挥杆结束后球仍在运动，也能在界面暂停、继续，继续不会重发一球。
打开视频面板会暂停球并隐藏轨迹；关闭后保持暂停。已有 MP4 仍是先前版本，不是本次实时运动的录像。
鼠标环绕、Tab、WASDQE、Home 和人物骨骼附着保持原有作用，不因轨迹开关改变。
实现保存在原生蓝图、运动组件、ISM 和材质中，没有自定义运行时 Python 或 C++。
当前验收见 Output/Validation/RealtimeTrajectory；以前 BallTrajectory 的预测路径检查仅是历史记录。
