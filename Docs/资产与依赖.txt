GolfHeadCam｜资产来源、依赖与迁移｜v1.1.0

开发与验证：Windows，Unreal Engine 5.8.3，EngineAssociation=5.8。
没有自定义 C++ 游戏模块，运行逻辑保存为原生蓝图；不需要临时作者脚本或 Python 插件。
MovieRenderPipeline 用于原生 MRQ/MP4 输出，ElectraPlayer 用于 UI 视频回放。
GameplayStateTree、ModelingToolsEditorMode 为官方模板保留的内置插件；后者仅编辑器。
UMG 和 MediaAssets 是引擎内置模块；没有引入第三方动作包、外部运行库或另购素材。

来源与实现边界
人物 SKM_Manny_Simple、骨架及相关资源复用 Epic Third Person Blueprint 模板。
Characters、ThirdPerson、Input、LevelPrototyping 等依赖目录完整保留。
工程自行编排 AS_GolfSwing 关键姿势、简化球杆/场地/球、相机、UI、球运动和畸变材质。
BP_GolfGolfer 控制挥杆、相机、实时球运动、实际轨迹和电影模式。
BP_GolfHUD 创建 WBP_GolfCameraConsole，后者继承 WBP_CameraControl。
BP_GolfGameMode 用于交互，BP_GolfRenderGameMode 用于无控制台的正式渲染。
M_HeadLensDistortion 为 278 个原生材质节点、8 次逆映射，无 Custom HLSL。
MI_HeadLens_Barrel/Pincushion 为原生预设，M_CalibrationGrid 为网格材质。
LS_Golf_HeadCamera/ThirdPerson 共享动作时轨；LS_Calibration_* 为静态对照。
MRQ_Golf_1080p60、Q_GolfViews 为保存的原生预设与队列。
两段 MP4 由本工程当前内容重新渲染，Content/Movies 与 Output 中的对应文件逐字节相同。
AI 辅助资料研究、编辑器作者工具、资产编排及验证整理；工具不参与游戏运行。
Epic 素材与引擎仍受其原有适用许可约束，本说明不改变权利归属。

迁移
完整解压，保留 GolfHeadCam.uproject、Config、Content 同级，用 UE5.8.3 打开。
首次打开等待资源和着色器加载，运行 L_GolfPractice；Tab 显示鼠标并点击播放。
不能只复制 Content/GolfHeadCam，因为它引用模板人物和其他依赖。
File Media Source 使用相对路径；输出预设使用 {project_dir}，不绑定作者机器的盘符。
完整项目包含 Output 下两段视频及 Content/Movies 下回放副本、报告、PPT、讲稿与验证。
不随包提供引擎、Saved/Intermediate/DerivedDataCache、作者工具及 720 张主视频原始帧；
选取的实际视频帧和四张镜头静态对照随包保留，可通过 MRQ 重建完整序列。

验证与限制
FullRelease：视频 19 项、资产 25 项、定向回归 8 项；此前实际交互 28 项见 RealtimeTrajectory。
其他目录保存历史证据，基础版的 271 或 UI 版 281 文件数不代表当前交付数量。
当前文件数、大小与哈希以 Deliverables/交付包内容清单.json 为准。
交付为可编辑工程，需 UE 引擎，未制作或宣称验证独立 EXE。
挥杆为简化动作；球的初速度/发射时间和镜头参数为假设，不是真实运动测量或实体标定。
未计算杆头冲量、空气动力学、自旋、滚动快门与传感器噪声。
