GolfHeadCam UE5 工程

用 UE5.8.3 打开 GolfHeadCam.uproject，保留同级 Config 和完整 Content。
主地图 /Game/GolfHeadCam/Maps/L_GolfPractice，点击 Play。
默认肩后第三人称待命，鼠标直接环绕；Tab 显示鼠标，点击控制台播放。
WASDQE 移动相机，Shift 加速，Home 复位，V 切换视角，T 显示实际轨迹，P 暂停或继续。
演示材料/演示材料_相机配置与效果验证.docx：相机安装与配置、内参与畸变参数、镜头效果及击球轨迹验证。
演示视频尚未上传，本次工程下载不包含 MP4。
实时场景可运行；已保存视频面板待提供对应媒体后使用。
