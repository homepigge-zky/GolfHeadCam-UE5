# 公开交付说明

整理日期：2026-10-17。目标：公开交付 GolfHeadCam 的全部非视频成果。原工作工程和本地含视频交付包保留不变。

## 包含内容

- 可编辑 UE5.8.3 工程：`.uproject`、完整非视频 Content 资产、Config。
- 根目录最新 5 页实验报告、10 页 PPT、约 10 分钟讲稿、原任务验收清单；早期实践报告在源码仓库中作为历史资料保留。
- 相机内参、镜头畸变、MRQ 导出参数、操作和蓝图说明、资产来源与依赖说明。
- 静态标定对照图、操作截图、历史与当前验证记录，以及公开文件 SHA-256 清单。

## 排除内容

- 所有视频文件，包括 Output 下正式视频以及 Content/Movies 中的回放副本。
- 两个视角共 720 张主视频逐帧 PNG；保留文档和验收所需的静态截图与标定图片。
- 引擎、Saved、Intermediate、DerivedDataCache、Binaries、临时制作环境及本地旧交付 ZIP。

## 历史文档的适用范围

根目录 `实验报告.pdf` 是当前版本，覆盖实时球运动、实际轨迹、肩后相机、鼠标环绕和 UI。`Deliverables/实践报告.pdf`、PPT、讲稿及原任务验收清单对应早期基础版：其中“已交付视频”和旧预设抛物线说明属于本地完整交付的历史记录。历史验证不能替代当前功能验收，作废会话也不能作为通过证据。

## 整合下载包

GitHub Release 提供 `GolfHeadCam_UE5_Project_Report.zip`。完整解压后顶层为 `GolfHeadCam/` 工程文件夹和一份 `实验报告.pdf`；工程内包含 `.uproject`、Content、Config 及其余非视频资料，不重复放置早期 PDF。工程需要 UE5.8.3 打开，不能只复制单个 `.uproject`。下载包内清单以 ZIP 根目录为路径基准，源码仓库清单以仓库根目录为基准。

`<PROJECT_DIR>`、`<UE_ROOT>`、`<AUTHOR_HOME>`、`<AUTHOR_TEMP>` 是文档与记录中本机路径的代称；不是新增的运行时路径配置。

公开文件清单位于同目录 `交付包内容清单.json`，其文件哈希不包含清单自身及 Git 元数据，以避免自引用。
